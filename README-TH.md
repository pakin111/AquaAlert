# AquaAlert — คู่มือเริ่มต้น

โปรเจกต์นี้เป็นต้นแบบแอปติดตามการดื่มน้ำ ใช้เว็บแอปเป็นหน้าจอและ Capacitor สำหรับเตรียมแพ็กเกจ iOS/Android

## ความสามารถที่มี
- เพิ่มน้ำด่วน 200 / 350 / 500 ml และกำหนดเอง
- คำนวณเปอร์เซ็นต์เทียบเป้าหมาย
- ตั้งเป้าหมายรายวัน
- ดูรายการที่บันทึกในวันนี้
- เก็บข้อมูลในเครื่องด้วย localStorage และเริ่มวันใหม่ด้วยข้อมูลรายวันชุดใหม่

## ข้อสำคัญ
ไฟล์ ZIP นี้คือ **ซอร์สโค้ดโปรเจกต์** ไม่ใช่ไฟล์ติดตั้ง `.ipa` หรือ `.apk` และยังไม่ได้ผ่านการ Build/ทดสอบบนอุปกรณ์จริง

## วิธี Build (ต้องใช้คอมพิวเตอร์หรือบริการ Cloud Build)
ติดตั้ง Node.js LTS ก่อน แล้วเปิด Terminal ในโฟลเดอร์โปรเจกต์:

```bash
npm install
npm run build
npx cap add android
npx cap add ios
npx cap sync
```

สำหรับ Android ต้องใช้ Android Studio เพื่อเปิดและ Build โฟลเดอร์ `android/`
สำหรับ iOS ต้องใช้ macOS และ Xcode เพื่อเปิดและ Build โฟลเดอร์ `ios/` รวมถึงการลงนามแอปด้วยบัญชี Apple Developer ตามวิธีเผยแพร่ที่เลือก

## ทดลองบน iPhone ตอนนี้
สามารถนำโฟลเดอร์นี้ไป Deploy เป็นเว็บโฮสต์ผ่านบริการที่รองรับ Vite ได้ก่อน แต่การเพิ่มลงหน้าจอโฮมแบบเว็บแอปยังไม่เท่ากับแอป native ที่ติดตั้งจาก App Store

## ข้อมูลส่วนบุคคล
ข้อมูลทดลองถูกเก็บไว้ใน localStorage ของเบราว์เซอร์บนอุปกรณ์นั้น ๆ ยังไม่มีบัญชีผู้ใช้หรือการซิงก์ข้ามอุปกรณ์
